🎬 CineRank — Instruções de Uso da API

📌 Base da API

A API é uma Google Apps Script Web App. Todas as rotas usam GET.

BASE_URL = https://script.google.com/macros/s/AKfycbxnq0OcYmMbs70VPbaRv2oEELh9tedda6bvcWKH_HNL4mNbDtEJX_5ZnDheSXr8y9y-MQ/exec

🛠️ Ferramentas recomendadas

  • Postman
  • REST Client (Chrome Extension)

⚠️ Observações gerais

  • Método: GET
  • Autenticação: nenhuma nas rotas públicas
  • Formato de data: YYYY-MM-DD
  • Campos nulos aparecem como null
  • genres, screenplay, cast são arrays
  • Parâmetros via query string

📬 Como usar no Postman

  • New → HTTP Request
  • Método: GET
  • Inserir URL
  • Send
  • Ver resposta em Body → JSON

🌐 REST Client (Chrome Extension)

  • Instalar extensão
  • Criar requisição
  • Método: GET
  • Enviar
  • Visualizar resposta
